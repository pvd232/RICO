# MANTRA Rebuild Phase 0 Archive

This directory preserves the Phase 0 contract declarations and evidence after
their workflow was retired. The archived files retain their original bytes.
Paths recorded inside receipts remain relative to the RICO repository layout
that existed when each receipt was written.

Compatibility links at the original `docs/contracts` and `evidence` paths keep
historical links and the Phase 1 baseline test resolvable. New contract work
uses the global `contract_protocol` package and the active declarations under
`contracts`, `checklists`, `plans`, and `evidence`.
